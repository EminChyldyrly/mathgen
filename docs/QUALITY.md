# Проверка качества

## Тесты

`python -m unittest discover -s tests` — 71 тест, около 2,5 с, внешних зависимостей нет.

Главная идея: ответ в ключе проверяется **независимо от генератора**. Тест берёт текст задачи, заново вычисляет обе части уравнения (или выражение с дробями), подставляет корень и убеждается, что решение единственное. Для текстовых задач числа достаются из условия регулярным выражением, ответ пересчитывается по формуле. Так ошибка в генераторе (например, перепутанный знак в тексте) не может «согласованно» попасть и в условие, и в ответ.

Дополнительно проверяются: детерминизм и воспроизводимость по `тема/уровень/seed`; отсутствие повторов в листках; стабильность seed при разных `PYTHONHASHSEED`; разбор десятков вариантов записи ответа; обратная связь проверки; сборка PDF с кириллицей и экранированием спецсимволов; команды CLI и коды возврата.

## Мутационная проверка

`python scripts/mutate.py` вносит в исходники по одной правке (смена `+`/`-`, `==`/`!=`, `and`/`or`, границ) и запускает тесты.

| Прогон | Мутаций | Убито | Выжило |
|---|---|---|---|
| 1 (60 тестов) | 232 | 200 | 32 |
| 2 (71 тест, после доработки) | 229 | 221 | 8 |

Первый прогон нашёл реальную ошибку в проверке систем: ответ с индексами (`x1=…, y1=…`) вызывал необработанное исключение. Она исправлена, добавлен тест. Остальные выжившие мутанты показали, что тесты не проверяли диапазоны генераторов, шаги решения в процентах и дробях, а также границу «приближённого» ответа; для них добавлены целевые тесты (`tests/test_targeted.py`).

Восемь оставшихся мутантов разобраны вручную, все они эквивалентны исходному коду:

- `c >= 0` вместо `c > 0` в `_sgn` — функции никогда не передают 0;
- `a >= 0` вместо `a > 0` в ветке «нет корней» — коэффициент `a` не бывает нулевым;
- смена знака в `b, c = -(r1 + r2), …` (три места) и `-2·a·r` — корни просто меняют знак, уравнение остаётся верным, а тесты подставляют корни, найденные по тексту;
- `st >= 1` вместо `st > 1` — при шаге 1 `randrange` и `randint` дают то же распределение;
- `hi - 1` вместо `hi + 1` в диапазоне скоростей — теряется только верхняя граница диапазона, условия остаются корректными.

Замечание для тех, кто будет запускать скрипт: он выключает запись байт-кода (`PYTHONDONTWRITEBYTECODE`). Без этого Python может взять устаревший `.pyc` от предыдущего мутанта, если файл переписан в ту же секунду.

## Что не проверено

- Педагогическая сложность уровней оценена только по структуре задач (целый или дробный ответ, наличие скобок, число шагов), без проверки на реальных учениках.
- PDF проверен извлечением текста и визуальным осмотром страниц, но не в разных просмотрщиках и не при печати.
